
usa **lowerCamelCase**  empieza con minúsculas la primera letra de cada palabra.
reglas para nombre de variables: 
- debe comenzar con una letra, un símbolo de dólar `$` o `_`
```
String nombre = "Juan";
String $apellido = "Gomez"
int _edad = "22"
```
- No pude contener espacio ni caracteres especiales.
```
Sting nombreCliente = "Juan";
```
- No puede ser una palabra reservada  de Java (Keyword).
```
// no usar 
int
for 
while
class
```
- Distingue entre mayusculas y minuscula.
```
String nombre;
String Nombre;
string NOMBRE; // son variables distintas 
```
