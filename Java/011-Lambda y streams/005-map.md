### `map`

`map` es una **operación intermedia de un `Stream`** que permite **transformar cada elemento** en otro valor.

A diferencia de `filter`, que decide qué elementos continúan, `map` modifica la **representación de cada elemento** para producir un nuevo elemento.

```
List<Integer> numeros = List.of(1, 2, 3);

numeros.stream()
       .map(n -> n * 2);
```

Conceptualmente:

```
1 → 2
2 → 4
3 → 6
```

Cada elemento de entrada pasa por una función que determina **qué elemento debe producirse como resultado**.

`map` recibe una **`Function`**, que es una interfaz funcional que representa una operación que recibe un valor y devuelve otro.

```
Elemento
   ↓
Function
   ↓
nuevo elemento
```

La transformación no tiene por qué producir el mismo tipo. Por ejemplo, podemos transformar objetos `Persona` en sus nombres:

```
personas.stream()
        .map(Persona::getNombre);
```

En ese caso:

```
Persona → String
```

Por eso `map` es especialmente importante cuando queremos **extraer información, convertir datos o cambiar la representación de los elementos** de un `Stream`.

Al igual que `filter`, `map` es una **operación intermedia** y no modifica la colección original.

La diferencia fundamental es:

```
filter
→ decide qué elementos continúan

map
→ transforma los elementos
```

> `map` permite **transformar cada elemento de un `Stream`**, aplicando una función que convierte cada elemento de entrada en un nuevo elemento.
