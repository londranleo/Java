### 1. Fundamentos de programación y Java básico

- Variables, tipos de datos, operadores
- Estructuras de control (if, switch, bucles)
- Arrays y colecciones básicas
- Métodos y modularización
- Programación orientada a objetos: clases, objetos, herencia, polimorfismo, encapsulamiento, abstracción, interfaces
- Manejo de excepciones
- Entrada/salida básica (Scanner, System.out)

### 2. Java intermedio

- Colecciones (List, Set, Map) y sus implementaciones
- Generics
- Streams y programación funcional (lambdas, Optional)
- Manejo de fechas (java.time)
- Lectura/escritura de archivos
- Multithreading básico (conceptos, no imprescindible a fondo al inicio)

### 3. Herramientas esenciales

- Git y GitHub (control de versiones)
- Maven o Gradle (gestión de dependencias y build)
- Uso de un IDE (IntelliJ IDEA recomendado)

### 4. Bases de datos

- SQL básico e intermedio (SELECT, JOIN, agregaciones, subconsultas)
- Diseño de bases de datos relacionales (normalización, claves)
- JDBC (conexión manual a bases de datos)
- Un motor: PostgreSQL o MySQL

### 5. Persistencia con ORM

- JPA (Java Persistence API)
- Hibernate como implementación
- Mapeo de entidades y relaciones

### 6. Spring Framework

- Spring Core (inyección de dependencias, contenedores)
- Spring Boot (configuración automática, arranque rápido)
- Spring MVC / Spring Web (creación de APIs REST)
- Spring Data JPA (repositorios)
- Validaciones (Bean Validation)
- Manejo global de excepciones en APIs

### 7. APIs REST en profundidad

- Diseño de endpoints RESTful
- Códigos de estado HTTP correctos
- DTOs y separación de capas (controller, service, repository)
- Documentación con Swagger/OpenAPI

### 8. Seguridad

- Autenticación y autorización
- Spring Security
- JWT (JSON Web Tokens)

### 9. Testing

- JUnit 5
- Mockito
- Testing de integración con Spring Boot Test

### 10. Temas de nivel profesional

- Manejo de logs (SLF4J, Logback)
- Variables de entorno y perfiles (application.properties/yml por entorno)
- Docker básico (contenerizar tu app)
- Caché (Redis, opcional pero valorado)
- Mensajería asíncrona (Kafka o RabbitMQ, opcional)
- Principios SOLID y patrones de diseño básicos
- Arquitectura en capas / hexagonal (introducción)

### 11. Práctica y portafolio

- Construir 2-3 proyectos completos (API REST + base de datos + seguridad + tests)
- Subirlos a GitHub con buen README
- Desplegar al menos uno (Render, Railway, o similar gratuito)
