Los **operadores aritméticos** permiten realizar operaciones matemáticas sobre valores numéricos. Se utilizan principalmente con los tipos numéricos de Java, como `byte`, `short`, `int`, `long`, `float` y `double`.

Los operadores aritméticos básicos son:

|Operador|Operación|
|---|---|
|`+`|Suma|
|`-`|Resta|
|`*`|Multiplicación|
|`/`|División|
|`%`|Módulo o resto|

### Suma `+`

Suma dos valores numéricos y devuelve el resultado de la operación.

```java
int resultado = 10 + 5; // 15
```

El operador `+` también puede utilizarse para **concatenar cadenas**, pero en ese caso deja de realizar una operación aritmética y pasa a unir texto.

### Resta `-`

Obtiene la diferencia entre dos valores.

```java
int resultado = 10 - 5; // 5
```

También puede utilizarse como operador unario para cambiar el signo de un valor, aunque esto pertenece al comportamiento de los operadores unarios.

### Multiplicación `*`

Multiplica dos valores y produce su producto.

```java
int resultado = 10 * 5; // 50
```

### División `/`

Divide un valor entre otro.

Su comportamiento depende de los tipos utilizados. Cuando ambos operandos son enteros, Java realiza **división entera**, por lo que la parte decimal del resultado se descarta.

```java
int resultado = 10 / 3; // 3
```

Si interviene un tipo decimal, el resultado puede conservar la parte fraccionaria:

```java
double resultado = 10.0 / 3; // 3.333...
```

Por tanto, `/` no siempre produce un resultado decimal; depende de los tipos de los operandos.

### Módulo `%`

El operador `%` obtiene el **resto de una división**.

```java
int resto = 10 % 3; // 1
```

Es especialmente útil para determinar si un número es divisible entre otro, comprobar si un número es par o impar y realizar operaciones que dependen de ciclos o posiciones.

### Promoción de tipos

Al realizar operaciones aritméticas con diferentes tipos numéricos, Java puede realizar una **promoción de tipos** para determinar el tipo utilizado durante la operación.

Por ejemplo, cuando se combinan determinados tipos enteros pequeños, como `byte` y `short`, las operaciones aritméticas normalmente se realizan como `int`. Si intervienen tipos de mayor capacidad, el resultado puede promocionarse a `long`, `float` o `double` según las reglas de Java.

Esto significa que **el tipo de los operandos influye directamente en el tipo y comportamiento del resultado**.

### División entre cero

La división entre cero debe tenerse en cuenta porque su comportamiento depende del tipo utilizado.

Con tipos enteros, intentar dividir entre cero provoca una `ArithmeticException`.

Con valores de coma flotante (`float` y `double`), Java utiliza las reglas de IEEE 754, por lo que una división entre cero puede producir valores como `Infinity` o `NaN` en determinadas situaciones.
