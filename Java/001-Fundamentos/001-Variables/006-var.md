# var

`var` es una palabra especial que puedes usar en Java para crear una variable sin tener que escribir tú mismo su tipo (por ejemplo, si es un número entero, un texto, etc.).

Cuando escribes `var`, Java mira el valor que le estás dando a la variable y adivina el tipo por ti automáticamente.

```java
var edad = 10;        // Java entiende que es un número entero
var nombre = "Ana";   // Java entiende que es un texto
```

Aunque tú no escribas el tipo, la variable sí que tiene un tipo por dentro (Java lo eligió solo), así que una vez creada funciona. Después no puedes darle un valor de otro tipo diferente.

`var` solo se puede usar cuando la variable se crea y se le da un valor en la misma línea, porque Java necesita ese valor para poder adivinar el tipo.
