Los **operadores** son símbolos o construcciones que permiten realizar una operación sobre uno o varios valores. Los valores sobre los que actúa un operador se denominan **operandos**.

Una expresión puede estar formada por valores, variables y operadores. Al evaluarla, Java aplica las operaciones indicadas y produce un resultado.

Por ejemplo:

```java
int resultado = 10 + 5;
```

Aquí `10` y `5` son los **operandos**, `+` es el **operador** y el resultado de la expresión es `15`.

Los operadores de Java se pueden clasificar según el tipo de operación que realizan:

- **Aritméticos** → realizan operaciones matemáticas.
- **Asignación** → asignan valores a variables.
- **Relacionales** → comparan valores.
- **Igualdad** → comprueban si dos valores son iguales o diferentes.
- **Lógicos** → combinan o niegan condiciones.
- **Unarios** → trabajan sobre un único operando.
- **Incremento y decremento** → aumentan o reducen un valor en una unidad.
- **Ternario** → permite seleccionar uno de dos valores según una condición.
- **Bit a bit** → trabajan directamente sobre los bits de los valores enteros.
