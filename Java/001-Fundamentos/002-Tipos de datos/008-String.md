# String

`String` es un tipo de dato de Java que se usa para almacenar texto, es decir, una secuencia de caracteres. A diferencia de los tipos primitivos.

Su valor se escribe entre comillas dobles.

```java
String nombre = "Ana";
```

Una característica importante de `String` es que sus valores son inmutables: una vez creado un texto, no puede modificarse. Cualquier operación que parezca cambiar un `String` en realidad crea un nuevo objeto con el resultado, en lugar de alterar el original.

Si no se le asigna ningún valor, su valor por defecto es `null`, que representa la ausencia de un objeto.
