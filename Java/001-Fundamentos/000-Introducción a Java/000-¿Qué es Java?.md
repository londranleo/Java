# ¿Qué es Java?

Java es un **lenguaje de programación** que se utiliza para crear programas y aplicaciones.

Es un lenguaje de **propósito general**, lo que significa que no está pensado para hacer una sola cosa. Con Java podemos crear desde programas sencillos hasta aplicaciones grandes, como sistemas empresariales, aplicaciones backend, APIs, microservicios y otros tipos de software.

Java es un lenguaje de **alto nivel**, por lo que su forma de escribir código está pensada para que sea relativamente fácil de entender para las personas. Por ejemplo:

```java
int edad = 25;
```

Aquí podemos entender fácilmente que estamos creando una variable llamada `edad` y guardando en ella el valor `25`, sin tener que trabajar directamente con las instrucciones internas del procesador.

Java está basado principalmente en la **programación orientada a objetos**, por lo que permite organizar los programas utilizando clases y objetos. Esto facilita la creación y organización de aplicaciones, especialmente cuando estas empiezan a crecer.

Una de las características más importantes de Java es la forma en la que ejecuta los programas. Cuando escribimos código Java, ese código no se ejecuta directamente. Primero se **compila** y se convierte en un código intermedio llamado **bytecode**.

```text
Código Java
    ↓
Compilación
    ↓
Bytecode
    ↓
Ejecución
```

Este bytecode puede ejecutarse en diferentes sistemas mediante la **JVM**. Gracias a esto, un mismo programa Java puede ejecutarse en Windows, Linux o macOS sin tener que crear una versión diferente del programa para cada sistema.

De aquí viene la conocida idea de Java:

```text
Write Once, Run Anywhere
```

Es decir, escribir el programa una vez y poder ejecutarlo en diferentes plataformas.
