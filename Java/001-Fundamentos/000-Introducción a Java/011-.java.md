# .java

**.java** es la extensión que identifica los archivos que contienen **código fuente** escrito en el lenguaje Java. Es el tipo de archivo que tú, como programador, creas y editas directamente.

Un archivo `.java` contiene el código legible que define, normalmente, una clase (aunque también puede contener interfaces, enumeraciones u otros elementos del lenguaje):

```java
public class Main {
    public static void main(String[] args) {
        int edad = 25;
    }
}
```

Una regla importante en Java es que, si una clase es **pública** (`public`), el nombre del archivo `.java` debe coincidir exactamente con el nombre de esa clase, incluyendo mayúsculas y minúsculas. Por ejemplo, la clase `public class Main` debe estar guardada en un archivo llamado `Main.java`.

Un archivo `.java` no puede ejecutarse directamente. Antes debe pasar por el proceso de **compilación**, en el que el compilador (`javac`) lo transforma en un archivo `.class`, que contiene el bytecode correspondiente y que sí puede ser interpretado y ejecutado por la JVM.

Por tanto, `.java` representa siempre el **punto de partida** de cualquier programa Java: el código que escribes antes de compilarlo y ejecutarlo.
