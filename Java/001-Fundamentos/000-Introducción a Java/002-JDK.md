# JDK

**JDK** (Java Development Kit) es el conjunto de herramientas que necesitas instalar en tu ordenador para poder **desarrollar programas en Java**.

Incluye todo lo necesario para escribir, compilar y ejecutar código Java, entre ello:

- El **compilador** (`javac`), que transforma el código que escribes (`.java`) en bytecode (`.class`), un formato que la máquina virtual de Java puede entender.
- Herramientas adicionales para depurar, documentar y empaquetar programas.
- El **JRE** (Java Runtime Environment), que es el entorno necesario para ejecutar programas Java, y que a su vez incluye la **JVM** (Java Virtual Machine), encargada de ejecutar el bytecode.

En resumen, el JDK contiene tanto lo necesario para **crear** programas Java como lo necesario para **ejecutarlos**, ya que lleva el JRE incluido.

Si solo quisieras ejecutar programas Java ya creados (sin programar), te bastaría con el JRE. Pero si vas a programar en Java, necesitas instalar el **JDK**.

Existen distintas distribuciones del JDK, como Oracle JDK, OpenJDK, Amazon Corretto o Eclipse Temurin, entre otras. Todas cumplen el mismo estándar del lenguaje Java, aunque pueden variar en licencias y soporte.

Cada nueva versión de Java trae consigo una nueva versión del JDK, por lo que es habitual ver referencias como "JDK 17" o "JDK 21", indicando la versión del lenguaje que soportan.
