# JRE

**JRE** (Java Runtime Environment) es el entorno necesario para **ejecutar** programas Java en un ordenador.

Su función es proporcionar todo lo que un programa Java necesita para funcionar, sin incluir las herramientas de desarrollo (como el compilador). Es decir, con el JRE puedes **ejecutar** programas Java, pero no puedes **crearlos ni compilarlos**.

El JRE incluye principalmente:

- La **JVM** (Java Virtual Machine), que es la encargada de interpretar y ejecutar el bytecode (`.class`) generado a partir del código Java.
- Las **librerías estándar** de Java, necesarias para que los programas puedan utilizar funcionalidades básicas del lenguaje (como manejo de texto, colecciones, entrada y salida de datos, etc.).

Cuando ejecutas un programa Java, es el JRE (a través de la JVM) quien se encarga de interpretar ese bytecode y traducirlo a instrucciones que tu sistema operativo pueda entender.

Si solo necesitas ejecutar aplicaciones Java ya creadas por otra persona, con instalar el JRE es suficiente. En cambio, si vas a programar en Java, necesitas el JDK, que ya incluye el JRE dentro de sí mismo.

Hoy en día, muchas distribuciones modernas del JDK (como OpenJDK) no ofrecen el JRE como una descarga independiente, y se recomienda instalar directamente el JDK, incluso si solo se va a ejecutar código Java.
