# .class

**.class** es la extensión de los archivos que contienen el **bytecode** generado tras compilar un archivo `.java`. Es el resultado del proceso de compilación, y no un archivo pensado para ser leído o editado directamente por el programador.

Cuando compilas un archivo `.java` con `javac`, se genera un archivo `.class` por cada clase, interfaz o enumeración definida en el código fuente. Por ejemplo, al compilar `Main.java`:

```text
javac Main.java
```

se genera un archivo `Main.class`.

Este archivo contiene instrucciones en bytecode, un formato intermedio que no está escrito en el lenguaje original de Java ni tampoco en código específico del procesador, sino en un formato pensado para que la **JVM** pueda interpretarlo y ejecutarlo.

Los archivos `.class` son los que realmente se ejecutan cuando lanzas un programa Java, por ejemplo con el comando `java Main` (haciendo referencia al archivo `Main.class`, sin escribir la extensión). Son también estos archivos, y no los `.java`, los que se distribuyen cuando se comparte un programa Java ya compilado, ya que contienen todo lo necesario para que la JVM lo ejecute sin necesidad de tener el código fuente original.

Un mismo archivo `.class` puede ejecutarse en cualquier sistema operativo que tenga una JVM instalada, sin necesidad de volver a compilarlo, ya que el bytecode que contiene es independiente de la plataforma.
