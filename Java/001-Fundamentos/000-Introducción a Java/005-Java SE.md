# Java SE

**Java SE** (Java Standard Edition) es la edición estándar de la plataforma Java, y sirve como base para todas las demás ediciones del lenguaje.

Define el núcleo del lenguaje Java: su sintaxis, sus tipos de datos, la programación orientada a objetos, y las **librerías fundamentales** que se utilizan en prácticamente cualquier programa Java, como el manejo de colecciones, texto, entrada y salida de datos, excepciones, hilos, etc.

Java SE incluye tanto la especificación del lenguaje como las herramientas necesarias para desarrollar y ejecutar aplicaciones Java: el **JDK** (para desarrollar) y el **JRE** (para ejecutar), ambos con su correspondiente **JVM**.

Se utiliza para crear aplicaciones de escritorio, herramientas de línea de comandos y, en general, cualquier programa Java que no dependa de un servidor o de tecnologías empresariales específicas.

Además de Java SE, existen otras ediciones construidas sobre ella, pensadas para necesidades más específicas:

- **Java EE** (actualmente conocida como Jakarta EE): añade herramientas y librerías para desarrollar aplicaciones empresariales y de servidor, como aplicaciones web.
- **Java ME**: pensada para dispositivos con recursos limitados, como sistemas embebidos.

Estas otras ediciones no sustituyen a Java SE, sino que se apoyan en ella, añadiendo funcionalidades adicionales sobre su base.

Cuando alguien instala un JDK para aprender o desarrollar en Java de forma general, normalmente está instalando el JDK de **Java SE**.
