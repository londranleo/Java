# JVM

**JVM** (Java Virtual Machine) es la máquina virtual encargada de **ejecutar** el bytecode generado al compilar un programa Java.

Cuando compilas un archivo `.java`, el compilador no lo convierte directamente en código que el sistema operativo pueda ejecutar, sino en un formato intermedio llamado **bytecode** (`.class`). La JVM es quien se encarga de leer ese bytecode y traducirlo, en tiempo real, a instrucciones que el sistema operativo y el hardware de tu ordenador puedan entender.

Gracias a este proceso, un mismo programa Java compilado una sola vez puede ejecutarse en cualquier sistema operativo (Windows, Linux, macOS...) siempre que ese sistema tenga una JVM instalada. Esto es lo que se conoce como el principio de **"escribe una vez, ejecuta en cualquier lugar"** (*write once, run anywhere*).

Además de ejecutar el bytecode, la JVM se encarga de otras tareas importantes durante la ejecución del programa, como:

- Gestionar la memoria automáticamente mediante el **recolector de basura** (*garbage collector*), que libera la memoria ocupada por objetos que ya no se utilizan.
- Verificar que el bytecode sea seguro antes de ejecutarlo.
- Optimizar el rendimiento del programa mientras se está ejecutando.

La JVM no es un programa único e igual para todos los sistemas, sino que existen implementaciones distintas adaptadas a cada sistema operativo, aunque todas ellas siguen la misma especificación y son capaces de ejecutar el mismo bytecode.

La JVM forma parte tanto del JRE como del JDK, ya que ambos la necesitan para poder ejecutar programas Java.
