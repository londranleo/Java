# Características principales

Java es un lenguaje de programación diseñado para crear aplicaciones de diferentes tipos y ejecutarlas en distintos sistemas sin tener que modificar el código para cada plataforma.

Sus principales características son:

- **Multiplataforma:** el código Java se compila en **bytecode**, que puede ejecutarse en cualquier sistema que disponga de una **JVM** compatible. Esto permite desarrollar una aplicación y ejecutarla en diferentes sistemas operativos sin recompilar el código para cada uno.
    
- **Orientado a objetos:** Java utiliza la **programación orientada a objetos (POO)** como base para estructurar las aplicaciones mediante objetos, clases y sus relaciones.
    
- **Tipado estático:** cada variable tiene un tipo determinado y el compilador comprueba que las operaciones realizadas sean compatibles con ese tipo. Muchos errores pueden detectarse antes de ejecutar el programa.
    
- **Gestión automática de memoria:** Java utiliza un **Garbage Collector (GC)** para detectar y liberar automáticamente la memoria que ya no está siendo utilizada por el programa. El programador no necesita liberar manualmente cada objeto.
    
- **Seguridad:** Java incorpora diferentes mecanismos para reducir determinados riesgos durante la ejecución, como el control de tipos, la gestión automática de memoria y las restricciones aplicadas por el entorno de ejecución.
    
- **Robusto:** está diseñado para detectar y controlar muchos errores durante la compilación y la ejecución. Además, proporciona mecanismos como el manejo de excepciones para controlar situaciones inesperadas.
    
- **Portátil:** el mismo programa puede trasladarse entre diferentes sistemas siempre que exista un entorno de ejecución Java compatible. Esto está relacionado con la generación de bytecode y su ejecución mediante la JVM.
    
- **Independiente de la arquitectura:** el bytecode generado por el compilador no está diseñado para una arquitectura de procesador concreta. La JVM se encarga de ejecutarlo sobre la plataforma correspondiente.
    
- **Compilado e interpretado:** el código fuente se compila a bytecode y posteriormente la JVM ejecuta ese bytecode. Para mejorar el rendimiento, la JVM puede utilizar técnicas como **JIT (Just-In-Time)** para convertir partes del bytecode en código nativo durante la ejecución.
    
- **Multihilo:** Java proporciona soporte para ejecutar varias tareas de forma concurrente dentro de una misma aplicación mediante **hilos (threads)**.
    
- **Alto rendimiento:** aunque Java utiliza una máquina virtual, la JVM incorpora optimizaciones durante la ejecución, como compilación JIT, que permiten obtener un rendimiento elevado en muchas aplicaciones.
    
- **Amplia biblioteca estándar:** Java proporciona numerosas clases y APIs para realizar tareas habituales, como trabajar con archivos, colecciones, fechas, cadenas de texto, entrada y salida de datos, redes y concurrencia.
    
- **Dinámico:** Java puede cargar determinadas clases y componentes durante la ejecución, permitiendo que una aplicación trabaje con tipos y funcionalidades que no necesariamente estaban completamente definidos en el momento de la compilación.
    
- **Distribuido:** Java proporciona APIs y mecanismos que facilitan la creación de aplicaciones capaces de comunicarse mediante redes y trabajar con sistemas distribuidos.
    
- **Sintaxis familiar:** su sintaxis está influenciada principalmente por lenguajes como C y C++, por lo que resulta estructuralmente familiar para quienes conocen esos lenguajes.
    

En conjunto, estas características permiten que Java sea un lenguaje adecuado para desarrollar aplicaciones que necesitan **portabilidad, seguridad, mantenimiento, concurrencia y capacidad de ejecución en diferentes plataformas**.
