la palabra clave `var` permite simplificar tu código, ya que no debes especificar el tipo de dato manualmente.

# Reglas 

- Solo para variables locales.
- Debe ser inicializada al declararse. 
- El tipo debe ser inferrible. 
```
var nombre = "Juan"; //String
var edad = "22"; //int
```

> [!NOTE] Nota
> No puede ser usado para definir variables de clases o parámetros de métodos
