### `Map`

`Map` es una estructura de datos que permite relacionar una **clave** con un **valor**. A diferencia de `List`, donde los elementos se identifican mediante posiciones, en un `Map` cada elemento se identifica mediante una clave.

La clave actúa como un **identificador** del valor.

```java
Map<String, String> usuarios = new HashMap<>();

usuarios.put("leo123", "Leo");
usuarios.put("ana456", "Ana");
```

Una característica fundamental es que **las claves son únicas**. No puede haber dos entradas con la misma clave. Si se introduce una clave que ya existe, normalmente se sustituye el valor que estaba asociado a ella.

Los valores, en cambio, **sí pueden repetirse**.

`Map` no es una implementación concreta, sino una **interfaz**. Existen diferentes implementaciones que ofrecen distintas características. La que vamos a estudiar ahora es `HashMap`.

La diferencia fundamental con las colecciones anteriores es:

```
List → elementos identificados por posición
Set  → elementos únicos
Map  → elementos identificados por una clave
```

>un `Map` representa una relación **clave → valor**, donde cada clave identifica de manera única un valor.
