## `Set`

`Set` es una **interfaz de Java** que representa una colección en la que **no se permiten elementos duplicados**.

A diferencia de `List`, una `Set` no está pensada para trabajar con posiciones mediante índices.

```java
Set<String> nombres = new HashSet<>();
```

Podemos añadir elementos con `add()`:

```java
nombres.add("Ana");
nombres.add("Luis");
nombres.add("Ana");
```

Aunque intentemos añadir `"Ana"` dos veces, el `Set` solo mantendrá una:

```java
Ana
Luis
```

### ¿Qué ocurre al añadir un duplicado?

`add()` devuelve un `boolean` que indica si el elemento se añadió realmente:

```java
boolean añadido = nombres.add("Ana");
```

- `true` → el elemento se añadió.
- `false` → el elemento ya existía.

Por ejemplo:

```java
Set<String> nombres = new HashSet<>();

System.out.println(nombres.add("Ana")); // true
System.out.println(nombres.add("Ana")); // false
```

### No utiliza índices

Con una `List` podemos hacer:

```java
nombres.get(0);
```

Pero con `Set` no podemos hacer esto, porque un `Set` **no proporciona acceso mediante índices**.

Para recorrerlo podemos utilizar `for-each`:

```java
for (String nombre : nombres) {
    System.out.println(nombre);
}
```

### ¿Para qué sirve?

`Set` resulta especialmente útil cuando lo importante es **tener elementos únicos**.

Por ejemplo, si queremos almacenar los nombres de usuarios conectados:

```java
Ana
Luis
Carlos
Ana  ← duplicado
```

Un `Set` evita automáticamente que `Ana` aparezca dos veces.

### `List` vs `Set`

```java
List
→ permite duplicados
→ tiene posiciones/índices
→ mantiene un orden de elementos

Set
→ no permite duplicados
→ no utiliza índices
→ se centra en la unicidad de los elementos
```

**Idea clave:** `Set` representa una colección de **elementos únicos**. Su característica principal es que no permite duplicados y no se utiliza mediante índices como una `List`.
