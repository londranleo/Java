# try

`try` es una estructura utilizada en Java para **encerrar código que puede producir una excepción**.

Su función no es evitar que ocurra la excepción, sino **indicar qué parte del código queremos someter al mecanismo de manejo de excepciones**.

La estructura básica es:

```java
try {
    // código que puede producir una excepción
}
```

Por sí solo, `try` **no permite manejar la excepción**. Normalmente se combina con `catch`, que será el encargado de reaccionar cuando se produzca una excepción.

```java
try {
    int numero = Integer.parseInt("abc");
}
```

En este caso, la conversión puede producir una excepción. Al estar dentro de `try`, Java puede transferir el control al bloque `catch` correspondiente.

Conceptualmente:

```
        try
         │
         ↓
 ¿se produce una excepción?
      /       \
    NO         SÍ
    ↓           ↓
continúa     catch
```

Es importante entender que cuando se produce una excepción dentro del `try`, **Java interrumpe la ejecución normal de ese bloque** y busca un `catch` compatible con la excepción.

Por tanto, `try` sirve para **delimitar el código cuyo comportamiento excepcional queremos gestionar**.

No debemos utilizar `try` indiscriminadamente alrededor de todo el programa. Lo recomendable es colocar dentro únicamente las operaciones que realmente pueden producir la excepción que queremos tratar.

>`try` define la zona del código en la que Java debe estar preparado para gestionar una excepción. Cuando ocurre una excepción dentro de esa zona, el flujo normal se interrumpe y puede pasar al `catch` correspondiente.
