## `if`

`if` es una estructura de control que permite **ejecutar un bloque de código únicamente cuando se cumple una condición**.

La condición debe producir un valor `boolean`, es decir, `true` o `false`.

Su estructura básica es:

```java
if (condición) {
    // código que se ejecuta si la condición es true
}
```

Java evalúa la condición:

- Si es `true`, ejecuta el código dentro de `{}`.
- Si es `false`, no lo ejecuta y continúa con el código que viene después.

Por ejemplo:

```java
if (edad >= 18) {
    System.out.println("Mayor de edad");
}
```

Si `edad` es `20`, se ejecuta el mensaje. Si `edad` es `15`, Java simplemente continúa con la siguiente instrucción.

La condición puede utilizar **operadores relacionales, de igualdad y lógicos**, por lo que también podemos combinar varias condiciones.

```java
if (edad >= 18 && tieneEntrada) {
    System.out.println("Puede entrar");
}
```

`if` no devuelve un valor; su función es **decidir si un bloque de instrucciones debe ejecutarse o no**.

>`if` permite tomar una decisión en el programa: **si una condición es verdadera, ejecuta un bloque de código; si es falsa, lo salta**.
