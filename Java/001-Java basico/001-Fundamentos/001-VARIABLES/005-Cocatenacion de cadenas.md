La concatenacion de cadena es el proceso de unir dos o mas cadenas para formar una nueva cadena. 

El operador `+` es la forma mas comun y sencilla para concatenar cadenas en Java.

```java
var nombre = "Jesus";
var apellido = "Gomez";

// Resultado
var nombreCompleto = nombre + " " + apellido;
// Nueva cadena: Jesus Gomez
```
