## `for`

`for` es una estructura de control que permite **repetir un bloque de código un número determinado de veces o mientras se cumpla una condición**.

Se utiliza especialmente cuando sabemos qué variable controla la repetición y cómo debe avanzar en cada vuelta.

Su estructura básica es:

```java
for (inicialización; condición; actualización) {
    // código que se repite
}
```

El `for` reúne en una misma estructura **tres partes relacionadas con el control del bucle**:

1. **Inicialización** → se ejecuta una sola vez, antes de comenzar el bucle. Normalmente se utiliza para crear e iniciar una variable.
2. **Condición** → se comprueba antes de cada vuelta. Mientras sea `true`, el bloque se ejecuta.
3. **Actualización** → se ejecuta después de cada vuelta y normalmente modifica la variable que controla el bucle.

Por ejemplo:

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

El funcionamiento sería:

```java
Inicialización → condición → código → actualización
                         ↑              ↓
                         └──────────────┘
```

La inicialización solo ocurre una vez. La condición se comprueba antes de cada repetición y la actualización se realiza después de ejecutar el bloque.

Al igual que `while`, si la condición es `false` desde el principio, el bloque **no se ejecuta ninguna vez**.

Una característica importante es que las tres partes del `for` son expresiones independientes. Incluso pueden omitirse determinadas partes, aunque la condición debe tratarse con cuidado porque si no existe una condición que permita terminar el bucle, puede producirse un **bucle infinito**.

El `for` es especialmente habitual para **recorrer secuencias de valores**, como los índices de un array o realizar una operación un número concreto de veces.

>`for` permite controlar una repetición concentrando en una sola estructura la **inicialización, condición y actualización** de la variable que controla el bucle.
