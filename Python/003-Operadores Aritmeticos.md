Permiten realizar operaciones matematicos sobre valores numericos 

Los operadores aritmeticos son:

| Operador   | Operacion                                           |
| ---------- | --------------------------------------------------- |
| `+`        | Suma                                                |
| `-`        | Resta                                               |
| `*`        | Multiplicacion                                      |
| `/` y `//` | Division tbm existe la divicion redondea a la baja  |
| `%`        | Modulo o resto                                      |
