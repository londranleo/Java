Consiste en mostrar información por pantalla, la función principal es `print`

Formas de mostrar datos 

```python
nombre = "juan"  
edad = 22  
  
print("Hola", nombre, "tienes", edad, "anios")  
  
print("Hola {} tienes {} anios".format(nombre, edad))  
  
print(f"Hola {nombre} tienes {edad} anios")
```
