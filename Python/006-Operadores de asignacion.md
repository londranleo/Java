Sirven para asignar un valor a una variable o modificar el valor que ya tiene.

| Operador | Ejemplo   | Significado                     |
| -------- | --------- | ------------------------------- |
| `=`      | `x = 5`   | Asigna el valor 5 a `x`.        |
| `+=`     | `x += 2`  | Suma 2 a `x`.                   |
| `-=`     | `x -= 2`  | Resta 2 a `x`.                  |
| `*=`     | `x *= 2`  | Multiplica `x` por 2.           |
| `/=`     | `x /= 2`  | Divide `x` entre 2.             |
| `//=`    | `x //= 2` | División entera.                |
| `%=`     | `x %= 2`  | Guarda el resto de la división. |
| `**=`    | `x **= 2` | Eleva `x` al cuadrado.          |

```python
x = 10
x += 5
print(x) #15
```
