Se utilizan para establecer una relacion entre 2 valores

Compara estos valores entre si y esta compracion produce un resultado de tipo boolean `True` o `False`.

Tiene el mismo nivel de prioridad es su evalucaion 

Los operadores relaciones tienen menor prioridad que los aritmeticos 


| Operador | Significado       |
| -------- | ----------------- |
| `>`      | Mayor que         |
| `<`      | Menor que         |
| `>=`     | Mayot o igual que |
| `<=`     | Menor o igual que |
| `!=`     | direfente         |
| `==`     | igual             |

```python
resulado = 10 < 20 #True
```
