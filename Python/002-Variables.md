En python tiene 3 tipos de datos, numeros, texto, boleanos y no hace falta poner el tipo de dato

```python
numero = 10
decimal = 10.99
cadena = "Juan"
valor = False

print(type(numero), numero)
print(type(decimal), decimal)
print(type(cadena), cadena)
print(type(valor), valor)
```

Tipado dinamico 

El tipado dimanico se puede asigar a la misma varible otro tipo de valor 

```python
valor = 10

print(valor)

valor = "Juan"

print(valor)
```
